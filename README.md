DWS Survivor Pool is an NFL survivor league for Dale Workforce Solutions. Pick one team to win each week—but you can only use each team once all season. A loss eliminates you; the last player standing wins.

## How it works

- Pick one NFL team to win each week.
- You cannot pick the same team twice in a season.
- Picks lock at that game's kickoff.
- If your pick loses, you are eliminated; tied games let you survive.
- Players who forget to pick receive a random eligible team.
- If more than one player survives the regular season, play continues through the playoffs.

## Run locally

```bash
npm install
npm run dev
```
